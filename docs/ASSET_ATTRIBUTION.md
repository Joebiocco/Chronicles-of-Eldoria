# Asset attribution and provenance

## Eldoria world map

`assets/eldoria-map.png`

The base Eldoria map was supplied by the user for use in this project. This build uses it as the map artwork and adds local interactive overlays. The user remains responsible for confirming any underlying ownership, redistribution, or third-party licensing rights associated with that supplied image before public commercial distribution.

## Local SVG icon system

`assets/icons/ui/sprite.svg`

The semantic interface/content icon sprite was created locally for this build from original geometric SVG paths and shapes. It has no runtime dependency on an external icon CDN or font.

It provides symbols for navigation, skill categories, resources, equipment, regions, quests, dungeons, enemies, and status effects. Data-authored emoji may remain as text fallbacks or secondary narrative glyphs.

## PWA icons

Files in `assets/icons/`, including standard, maskable, and Apple touch variants, were generated locally for this project.

## Screenshots

- `assets/screenshot-wide.png`
- `assets/screenshot-map.png`
- `assets/screenshot-mobile.png`

These were generated by the browser QA suite from the executable game. They are declared in `manifest.webmanifest`.

## Audio

Files in `assets/audio/` were synthesized locally for this build. They are short interface and combat cues rather than copied music or commercial sound recordings.

## Fonts

The production build does not import remote web fonts. It uses local system font stacks.

## Source code and inherited content

The release extends the user-provided SimpleScape/Eldoria project and its authored content. No third-party runtime JavaScript library is bundled. Development tooling uses Node.js and Playwright in the build/test environment, but the deployed game does not require them.

## Runtime network dependencies

The static local-first build has no required third-party runtime network request. Supabase is not activated. Optional browser installation, notification APIs, and a future cloud adapter depend on platform support or later configuration, not external assets embedded in this release.
